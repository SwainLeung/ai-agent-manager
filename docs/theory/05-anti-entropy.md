# 05 — Anti-entropy governance

Agent systems accumulate stale prompts, duplicate skills, oversized memory,
orphaned data sources, temporary files, and noisy logs. Anti-entropy work makes
this drift observable and gives each asset an owner, lifecycle state, access
signal, and cleanup policy.

Typical audits look for duplicate signatures, low success, lifecycle stalls,
expired temporary data, and inactive capabilities. Cleanup must be staged and
reversible when it can affect future behavior.
