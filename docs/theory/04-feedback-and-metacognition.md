# 04 — Feedback and metacognition

Separate durable profile rules from temporary project rules. Treat undo, redo,
pitfall, fallback, correction, and approval signals as evidence rather than
immediate permanent truth.

A feedback store can aggregate repeated high-confidence signals into candidate
rules. Candidates should be reviewable, scoped, versioned, and reversible. A
later correction should be able to weaken or remove a rule that no longer
serves the user or project.
