# 03 — Skills versus Scripts

Use a Skill when the task is ambiguous, language-heavy, creative, or requires
dynamic planning. Use a Script when inputs and outputs are structured, the
algorithm is known, repeatability matters, or latency and cost are strict.

Repeated successful Skill behavior can be distilled into a deterministic
Script. The Script becomes the preferred fast path, while the original Skill
remains a fallback for unexpected inputs. This is an evolution path, not a
claim that one form is always superior.
